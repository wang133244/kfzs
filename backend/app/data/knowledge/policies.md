# 店铺售后与客服政策

本政策适用于店铺全部在售商品。客服人员回答售后问题时，应优先引用本政策原文，不承诺政策之外的口头补偿。
如平台规则与本政策冲突，以平台最新规则为准。

# 7 天无理由退换货

自签收次日起 7 天内，商品保持完好、配件齐全、不影响二次销售时，支持无理由退换。

适用条件：

- 商品外观无划痕、无使用痕迹，吊牌、包装、说明书、赠品齐全。
- 灯具需保持灯体、灯罩、配件完好，说明书与包装齐全。
- 定制尺寸或已安装固定的灯具，是否支持无理由退换以下单页标注为准。

处理流程：

1. 联系在线客服或提交售后申请，说明退换原因。
2. 客服审核通过后生成退换货工单。
3. 用户按客服提供的地址寄回商品，保留快递单号。
4. 仓库验收无误后，退款原路退回或按用户要求换货发出。

退款到账时间一般为 1-3 个工作日，具体以支付渠道到账时间为准。

# 退款流程

退款申请提交后，系统会自动生成审批工单。退款必须在人工客服审核通过后执行，系统不会自动打款。

退款类型说明：

- 未发货退款：审核通过后通常当天原路退回。
- 已发货退款：需先拦截物流或收到退货后再退款。
- 质量问题退款：审核通过后原路退回，运费由店铺承担。
- 无理由退款：退回运费由用户承担，商品需保持完好。

注意事项：

- 退款金额以订单实付金额为准，不含优惠券、积分等虚拟抵扣。
- 使用优惠券的订单退款后，优惠券是否返还以平台规则为准。
- 退款进度可在订单详情中查看，也可以联系在线客服查询工单状态。

# 发货政策

现货商品付款后 48 小时内发货，预售商品以商品详情页标注的发货时间为准。

发货说明：

- 默认使用顺丰或中通快递，偏远地区可能使用其他快递。
- 同一订单多件商品可能分包裹发出，物流单号以订单详情为准。
- 大促或天气等不可控因素可能导致延迟，发货后会第一时间更新物流。
- 收货地址错误、电话无法接通时，快递可能被退回，请及时核对收件信息。

# 物流查询

物流状态以快递公司实时数据为准。发货后可在订单详情中查看物流公司、运单号与最新轨迹。

常见情况处理：

- 物流长时间不更新：请先确认是否已过揽收时间，超过 48 小时无更新可联系客服核实。
- 包裹显示签收但未收到：请先检查快递柜、前台或家人代收，仍未找到可联系客服协助查询。
- 包裹破损或漏件：请保留面单与开箱照片，联系客服补发或发起退款。
- 快递退回：请及时更新正确地址，客服确认后重新安排发出。

# 投诉处理

投诉工单会在 24 小时内由人工客服处理。涉及质量、漏发、错发等问题，请保留商品照片与快递面单。

投诉处理流程：

1. 用户描述问题并提交相关凭证。
2. 系统自动生成投诉工单并转人工处理。
3. 客服在 24 小时内联系用户核实并给出处理方案。
4. 复杂问题最长不超过 3 个工作日闭环，处理结果同步到订单或工单记录。

建议用户保留的材料：

- 商品外观与瑕疵部位照片
- 快递外包装与面单照片
- 开箱或使用问题视频
- 与客服的沟通记录

# 商品保修政策

非人为损坏且在保修期内的商品，支持免费维修或换新。保修期自签收起算。

各品类保修期：

- 太阳能柱头灯、户外壁灯、太阳能庭院灯：12 个月

不属于保修范围的情况：

- 人为摔落、进水、私自拆修造成的损坏
- 正常使用产生的磨损、氧化、色差
- 灯罩、密封圈等易耗件的正常损耗
- 超过保修期且无延保服务的商品

# 发票说明

商品默认开具电子发票，确认收货后可在订单详情中申请开票。
企业用户如需专票，请在开票信息中填写完整的公司名称、税号、注册地址与开户行信息。

# 客服工作时间与联系渠道

- 在线客服：每天 9:00-22:00
- 售后工单：24 小时可提交，处理时间为工作时段
- 投诉升级：如对处理结果不满意，可在工单中申请升级，由店铺负责人复核

# 购物、客服与安装常见问答

购买方式：在小程序橱窗选择灯具加入购物车，使用钱包余额结算下单即可。

客服营业时间：在线客服每天 9:00-22:00 在线；售后工单 24 小时可提交，工作时段处理。

运费与包邮：本店在售灯具支持全国包邮，偏远地区以商品详情页说明为准。

发票：商品默认开具电子发票，确认收货后可在订单详情中申请开票。企业用户如需专票，请填写完整开票信息。

钱包支付：下单时使用小程序钱包余额结算；余额不足请先充值后再下单。

保修：非人为损坏且在保修期内支持免费维修或换新，灯具保修期自签收起 12 个月。

安装接线：太阳能款通常无需市电布线，按说明书固定即可；市电壁灯请按说明书接线，建议由持证电工安装，请勿带电操作。

# 特殊场景处理

- 错发商品：客服核实后安排免费退回，并补发正确商品。
- 漏发配件：客服确认后免费补寄，无需退回整单。
- 质量问题退换：运费由店铺承担，用户先行垫付后凭快递面单退回。
- 退款失败：多为银行卡或支付账户状态异常，请核对账户后重新发起或联系客服处理。
